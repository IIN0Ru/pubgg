## 만든 것

**검색·전적**
- [x] 첫 화면(히어로): 로고, 스팀/카카오 선택, 닉네임 검색창. 빈 닉네임·잘못된 플랫폼이면 첫 화면으로 돌려보냄
- [x] PUBG API 연결: 닉네임 검색 → 최근 30경기 목록
- [x] 경기 필터(경쟁/일반, FPP/TPP)·더 보기·펼쳐보기(팀원 기록)
- [x] 이번 시즌 경쟁전 티어·RP + 최근 10경기 vs 시즌 비교
- [x] 자주 같이 한 팀원
- [x] 즐겨찾기·최근 검색 (브라우저 저장)
- [x] 검색 결과 저장 + 전적 갱신 버튼 (2분 대기)
- [x] 다크/라이트 모드, 검색 중 표시, 링크 미리보기 문구(og), 폰 배치

**플레이 카드 (A카드: 전적 화면, 기록만·수정 불가)**
- [x] 경쟁전 최근 10경기 기준 KDA, 평균 딜량, 평균 투척, 시점, 주무기·보조무기(두 번째로 오래 든 주무기, 공식 총 그림과 사용 비중)
  - 경쟁전이 한 판도 없으면 일반 경기 기준으로 만든다
- [x] 자기장 운영(줄어들기 시작할 때 위치, 인게임 미니맵형) + 자기장 운(새 원이 뜬 직후 위치)
- [x] 파밍: 대도시파밍/짤파밍, 3페이즈 시작 때 힐템·투척 보유량, 주운 총알
- [x] 티어 도트 테두리, 4개 맵 중 랜덤 맵·랜덤 구역 배경, 전투 태그(기록에서 자동)

**공유 카드 (B카드: `/card`, 공유할 때만 만듦)**
- [x] 성향 태그를 직접 고름: 마이크·접속 시간대·지향·구함·역할
- [x] 공유 링크(`/s/{id}`) + 링크 미리보기(`og:image`), PNG 저장
- [x] 같은 플레이어가 새로 공유하면 이전 공유의 그림만 비움("일회용"), 같은 접속 주소는 10분에 10번까지

**2D 리플레이 (경쟁전)**
- [x] 재생·배속·타임라인, 경기 흐름 누르면 이동, 근처 적만, 동선 전체 + 교전 번호, 확대·이동·따라가기
- [x] 고해상도 지도 조각(타일)을 보이는 만큼만 불러오기, 명중선, 차량·보급 아이콘, 폭발물(터진 곳 추정)·회복 이펙트
- [x] 체력 바, 죽기 전 30초 받은 피해, 교전 지표(기절→킬·복수·살림), 장면 링크(`?t=`), 킬 글에 무기·거리·헤드샷

**기반**
- [x] 검색 결과 화면을 React + TypeScript로 분리 (Spring은 JSON API만)
- [x] Java·프론트 테스트 + GitHub Actions CI
- [x] Docker 배포 (PostgreSQL에 공유 카드·텔레메트리 분석 결과 저장)
